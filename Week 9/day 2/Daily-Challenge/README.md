# Daymark — Daily Planner

A React and Redux daily planner for organizing tasks by date.

## Run locally

```sh
npm install
npm run dev
```

## Features

- Navigate a monthly calendar and select any date.
- Add tasks with a time and optional notes.
- Edit or delete tasks for the selected day.
- View each day's tasks in chronological order.
- Save planner data in browser local storage.
