# Daymark — Todos by Category

A React and Redux todo list with Personal, Work, and Learning categories.
Every todo stays in its category while it is added, completed, or removed.

## Run locally

```sh
npm install
npm run dev
```

## Features

- Add a task to the selected category.
- Mark tasks complete or active within their category.
- Remove tasks from their category.
- View task and completion counts for each category and the overall list.
