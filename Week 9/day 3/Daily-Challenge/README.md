# Daymark — Daily Planner

A daily planner built with React, Redux Toolkit, and React-Redux hooks. Tasks
are organized by date and can be added, edited, or removed.

## Run locally

```sh
npm install
npm run dev
```

## Features

- Select a date using the date picker or quick day navigation.
- Add, edit, and delete tasks for the selected date.
- View task counts and an empty state for dates with no tasks.
